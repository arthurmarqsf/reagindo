# Reagindo — app de React ao vivo

PWA pra fazer react de vídeos: escolhe o vídeo, sua câmera aparece por cima, pausa pra comentar, solta emoji e balão de texto, e grava tudo (vídeo + você + sua voz) num MP4.

**Abrir:** https://arthurmarqsf.github.io/reagindo/

## Instalar no iPhone
1. Abra o link no **Safari**
2. Botão **Compartilhar** → **Adicionar à Tela de Início**
3. Abra pelo ícone e permita câmera e microfone

## Recursos
- Vídeo do celular (Fotos/Arquivos) **ou** link do YouTube
- Formatos: câmera no canto 9:16, tela dividida 9:16, câmera no canto 16:9
- Toque no vídeo = pausa; selo "PAUSEI PRA COMENTAR"; lista de momentos pausados
- Balão de comentário, chuva de emojis, câmera arrastável (círculo/retângulo)
- Abaixa o som do vídeo sozinho quando você fala
- Gravação em MP4 → Salvar no rolo da câmera
- Com link do YouTube a gravação interna não é permitida: use a Gravação de Tela do iPhone
